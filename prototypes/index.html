Social Jackets

A student-focused community page with fictional student demo profiles, a newest-first feed, compact text composer, and campus activity and event fixtures. New posts last for the current page session. Event and linked-record details open locally; geographic map and discovery destinations are not wired in Thermal.

Open Social Jackets

Social Jackets profiles, posts, clubs, and events are fictional student demo data. They are not real student accounts or event listings. The existing path and alum reply flow remains a separate demo. Thermal loads libraries from CDNs and needs an internet connection.

Open prototypes/README.md for run instructions and prototype limitations.
